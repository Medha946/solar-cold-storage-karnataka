# Data

The project uses data from the following sources:

- **AGMARKNET** – crop arrivals and market prices
- **NASA POWER** – temperature and solar irradiance
- **ICAR-CIPHET** – crop-specific post-harvest loss data
- **National Horticulture Board (NHB)** – existing cold storage infrastructure

The datasets are preprocessed and integrated before forecasting, shelf-life estimation, machine learning, and infrastructure recommendation.
